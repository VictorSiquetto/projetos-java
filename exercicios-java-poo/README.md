# ☕ Exercícios de Java POO - Curso em Vídeo

Minhas resoluções dos desafios propostos no curso de Java POO do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

Os arquivos deste repositório acompanham a sequência de aprendizado das aulas, servindo como registro da minha prática e evolução nos conceitos de Programação Orientada a Objetos (POO).

## 📚 Assuntos Abordados

* **Conceitos Básicos:** Criação de Classes, Objetos e Instanciação
* **Visibilidade:** Modificadores de acesso (`public`, `private`, `protected`)
* **Métodos Especiais:** Métodos Construtores, Getters e Setters
* **Encapsulamento:** Proteção de dados e uso de Interfaces
* **Relacionamento entre Classes:** Agregação e troca de mensagens entre objetos
* **Herança:** Superclasses, subclasses, classes abstratas e árvore hierárquica
* **Polimorfismo:** Sobreposição (Overriding) e Sobrecarga (Overloading)
* **Exercícios Práticos:** Projetos integradores (como o exemplo da Conta Bancária, Lutadores UEC e Projeto YouTube) para consolidar a teoria
