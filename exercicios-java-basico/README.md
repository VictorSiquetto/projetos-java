# ☕ Java Básico - Curso em Vídeo

Minhas resoluções dos desafios propostos no curso de Java Iniciante do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

Os arquivos deste repositório acompanham a sequência de aprendizado das aulas, servindo como registro da minha prática e evolução durante o curso na linguagem Java.

## 📚 Assuntos Abordados

* **Configuração do Ambiente:** Preparação do JDK e IDE (NetBeans)
* **Fundamentos:** Tipos primitivos, manipulação de Strings e saída de dados
* **Operadores:** Aritméticos, lógicos, relacionais e classe Math
* **Estruturas Condicionais:** Condicionais simples e compostas (`if`, `else`, `switch`)
* **Estruturas de Repetição:** Laços com teste no início (`while`), no final (`do-while`) e com variável de controle (`for`)
* **Vetores:** Declaração e manipulação de arrays unidimensionais
* **Métodos:** Introdução à criação de rotinas e funções básicas
